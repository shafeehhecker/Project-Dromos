# Project-Dromos
Rust-based Critical Path Method (CPM) scheduling engine. Replaces a Python prototype with a natively compiled, memory-safe architecture using Tauri, SQLite (sqlx), and serde. Features O(V+E) topological sorting via Kahn's Algorithm, async I/O, and Tokio/Rayon concurrency. Compiles to a standalone binary for Windows, macOS, and Linux.
